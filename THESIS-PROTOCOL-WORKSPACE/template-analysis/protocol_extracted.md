| 5\. Why this study is required?  | -   Pulpitis is a sequelae to an |
| Please provide justification     |     insult of dental pulp by     |
|                                  |     microbial, chemical, or      |
|                                  |     physical irritants           |
|                                  |     (mechanical and thermal).^1^ |
|                                  |     According to the American    |
|                                  |     Association of Endodontics   |
|                                  |     (AAE) consensus on           |
|                                  |     diagnostic terminology,      |
|                                  |     pulpitis can be either       |
|                                  |     reversible or                |
|                                  |     irreversible.^2^ Teeth       |
|                                  |     diagnosed with irreversible  |
|                                  |     pulpitis are characterized   |
|                                  |     by having spontaneous,       |
|                                  |     intense and lingering pain   |
|                                  |     (often lasting 30 seconds or |
|                                  |     more after stimulus removal) |
|                                  |     that is often triggered by   |
|                                  |     thermal stimuli.^2^          |
|                                  |                                  |
|                                  | -   One study found that more    |
|                                  |     than 50% of patients         |
|                                  |     diagnosed with symptomatic   |
|                                  |     irreversible pulpitis (SIP)  |
|                                  |     presented with mechanical    |
|                                  |     allodynia, indicating a      |
|                                  |     significant incidence of     |
|                                  |     percussion sensitivity in    |
|                                  |     this condition.^37^          |
|                                  |     Reportedly, pain due to      |
|                                  |     irreversible pulpitis is the |
|                                  |     etiological factor for more  |
|                                  |     than 45% of emergency dental |
|                                  |     visits. Mechanical allodynia |
|                                  |     in irreversible pulpitis may |
|                                  |     be attributed to various     |
|                                  |     factors, including           |
|                                  |     activation of pulpal         |
|                                  |     mechanoreceptive nociceptive |
|                                  |     neurons, diffusion of        |
|                                  |     inflammatory mediators or    |
|                                  |     bacterial byproducts into    |
|                                  |     the periradicular space, and |
|                                  |     central sensitization        |
|                                  |     resulting from the           |
|                                  |     activation of pulpal         |
|                                  |     nociceptors.^37^             |
|                                  |                                  |
|                                  | -   The preferred treatment of   |
|                                  |     choice in such a scenario    |
|                                  |     will be conventional non-    |
|                                  |     surgical endodontic          |
|                                  |     treatment (NSET) which has a |
|                                  |     success rate of 95% with an  |
|                                  |     excellent prognosis.^6^      |
|                                  |     However, a small proportion  |
|                                  |     of patients may still        |
|                                  |     experience post-operative    |
|                                  |     pain following root canal    |
|                                  |     procedure, prevalence of     |
|                                  |     which ranges from 3% - 58%   |
|                                  |     ^8,10^. One of the many      |
|                                  |     reasons resulting in post    |
|                                  |     operative pain following     |
|                                  |     NSET is due to persistent    |
|                                  |     sensitivity to percussion.   |
|                                  |     Occlusal reduction is a      |
|                                  |     technique that has shown     |
|                                  |     promising results for        |
|                                  |     managing postoperative pain  |
|                                  |     by addressing occlusal       |
|                                  |     discrepancies and managing   |
|                                  |     percussion sensitivity.^9^   |
|                                  |                                  |
|                                  | -   Occlusal reduction involves  |
|                                  |     the intentional reduction of |
|                                  |     the occlusal surface of the  |
|                                  |     tooth to achieve evenly      |
|                                  |     balanced and distributed     |
|                                  |     occlusal forces across the   |
|                                  |     dental arch.^9,11^ Reducing  |
|                                  |     occlusal contacts may lower  |
|                                  |     the mechanical stimulation   |
|                                  |     of peripheral nociceptor     |
|                                  |     terminals which are believed |
|                                  |     to decrease pain levels and  |
|                                  |     the effects of mechanical    |
|                                  |     allodynia and relieve the    |
|                                  |     symptoms of percussion       |
|                                  |     sensitivity.^9,12^           |
|                                  |                                  |
|                                  | -   It is important to note that |
|                                  |     the effectiveness of         |
|                                  |     occlusal reduction in        |
|                                  |     reducing post-operative pain |
|                                  |     may vary depending on        |
|                                  |     individual patient factors,  |
|                                  |     the specific diagnosis of    |
|                                  |     the tooth being treated, pre |
|                                  |     operative pain score, and    |
|                                  |     periapical status of the     |
|                                  |     tooth.^14^ Study by Ahmed    |
|                                  |     et.al.,(2020) showed that    |
|                                  |     occlusal reduction was       |
|                                  |     associated with              |
|                                  |     significantly less pain      |
|                                  |     intensity at 12h and 24h     |
|                                  |     post-instrumentation.        |
|                                  |     Additionally, the study      |
|                                  |     found a decrease in          |
|                                  |     postoperative analgesic      |
|                                  |     intake in the occlusal       |
|                                  |     reduction group,             |
|                                  |     highlighting the potential   |
|                                  |     benefits of this             |
|                                  |     intervention in managing     |
|                                  |     post-operative pain.         |
|                                  |     Systematic reviews mentioned |
|                                  |     the potential benefit of     |
|                                  |     occlusal reduction while     |
|                                  |     mentioning the need for      |
|                                  |     further high-quality         |
|                                  |     clinical trials to better    |
|                                  |     understand its               |
|                                  |     role.^9,11,12^               |
|                                  |                                  |
|                                  | -   In recent times, there has   |
|                                  |     been a paradigm shift in     |
|                                  |     treating teeth diagnosed of  |
|                                  |     SIP with Vital Pulp Therapy  |
|                                  |     (VPT). Pulpotomy is one of   |
|                                  |     the minimally invasive       |
|                                  |     treatment modalities under   |
|                                  |     VPT. Based upon clinical and |
|                                  |     radiographic evaluation, two |
|                                  |     types of pulpotomy can be    |
|                                  |     performed in teeth with SIP: |
|                                  |     Full and Partial             |
|                                  |     pulpotomy.^15^ Full          |
|                                  |     pulpotomy refers to the      |
|                                  |     complete removal of the      |
|                                  |     coronal pulp and application |
|                                  |     of a biomaterial directly    |
|                                  |     onto the pulp tissue at the  |
|                                  |     level of the root canal      |
|                                  |     orifice(s), prior to         |
|                                  |     placement of a permanent     |
|                                  |     restoration.^15^ In cases of |
|                                  |     pulpotomy, where the coronal |
|                                  |     pulp is removed to treat     |
|                                  |     irreversible pulpitis, the   |
|                                  |     formation of tertiary dentin |
|                                  |     is observed at the site of   |
|                                  |     the pulp exposure as a       |
|                                  |     reparative process initiated |
|                                  |     by remaining radicular       |
|                                  |     pulp.^16^                    |
|                                  |                                  |
|                                  | -   The success rate of          |
|                                  |     pulpotomy using Biodentine   |
|                                  |     in young permanent teeth     |
|                                  |     with carious exposure was    |
|                                  |     reported to be 95% at 1-year |
|                                  |     follow-up.^17^ The study     |
|                                  |     demonstrated high clinical   |
|                                  |     and radiographic success     |
|                                  |     rates, with most cases       |
|                                  |     showing total pain relief    |
|                                  |     with dentin bridge formation |
|                                  |     and healing of periapical    |
|                                  |     rarefaction.^17^ Asgary S et |
|                                  |     al (2010)^18^ in their study |
|                                  |     compared postoperative pain  |
|                                  |     relief after single visit    |
|                                  |     NSET and pulpotomy and       |
|                                  |     concluded that the mean pain |
|                                  |     intensity and duration were  |
|                                  |     significantly lower in the   |
|                                  |     full pulpotomy group.^18^    |
|                                  |     The literature thus          |
|                                  |     indicates lower levels of    |
|                                  |     post operative pain after    |
|                                  |     pulpotomy was performed in   |
|                                  |     teeth diagnosed with SIP.    |
|                                  |     One study highlights a high  |
|                                  |     success rate of patients     |
|                                  |     undergoing full pulpotomy    |
|                                  |     but varying levels of        |
|                                  |     postoperative pain, with     |
|                                  |     approximately one-third of   |
|                                  |     patients reporting some      |
|                                  |     degree of pain.^21^ Galani   |
|                                  |     et.al. (2017) noted that 70% |
|                                  |     of patient following full    |
|                                  |     pulpotomy had slight to      |
|                                  |     moderate pain on 1st day and |
|                                  |     then from following day      |
|                                  |     onwards reported no to very  |
|                                  |     slight pain till fifth day   |
|                                  |     after treatment. Notably,    |
|                                  |     the study found that         |
|                                  |     continued pain at the        |
|                                  |     3-month evaluation point was |
|                                  |     significantly associated     |
|                                  |     with an unfavourable outcome |
|                                  |     of VPT, emphasizing the      |
|                                  |     importance of monitoring     |
|                                  |     postoperative pain as a      |
|                                  |     predictor of treatment       |
|                                  |     success.^20,21^              |
|                                  |                                  |
|                                  | -   Our hypothesis is mechanical |
|                                  |     allodynia is one of the      |
|                                  |     reasons for the occurrence   |
|                                  |     of post operative pain in    |
|                                  |     teeth with SIP and           |
|                                  |     sensitivity to percussion    |
|                                  |     treated with full pulpotomy, |
|                                  |     and by occlusal reduction    |
|                                  |     the incidence of post        |
|                                  |     operative pain may be        |
|                                  |     minimized by relieving the   |
|                                  |     tooth from mechanical        |
|                                  |     allodynia. Until now there   |
|                                  |     is no study in the           |
|                                  |     literature which has         |
|                                  |     evaluated the effect of      |
|                                  |     occlusal reduction on post   |
|                                  |     operative pain following     |
|                                  |     full pulpotomy performed in  |
|                                  |     permanent mature mandibular  |
|                                  |     molar teeth with symptomatic |
|                                  |     irreversible pulpitis and    |
|                                  |     sensitivity to percussion.   |
|                                  |     Therefore, the current study |
|                                  |     aims to evaluate the effect  |
|                                  |     of occlusal reduction on     |
|                                  |     post operative pain and      |
|                                  |     outcome of full pulpotomy    |
|                                  |     performed in permanent       |
|                                  |     mature mandibular molar      |
|                                  |     teeth with symptomatic       |
|                                  |     irreversible pulpitis and    |
|                                  |     sensitivity to               |
|                                  |                                  |
|                                  |    percussion**[.]{.underline}** |

| 6\. Methodology                  | **Sample size calculation**      |
|                                  |                                  |
|                                  | Sample size is calculated based  |
|                                  | study done by Taha et al (2023), |
|                                  | considering the average pain     |
|                                  | score following pulpotomy to be  |
|                                  | 2.19 ± 3.25 during seven days    |
|                                  | and on assuming a small          |
|                                  | effective size of 0.15           |
|                                  | (0.5/3.25) between Occlusal      |
|                                  | reduction and Non-occlusal       |
|                                  | reduction groups (i.e, 0.15 less |
|                                  | in O.R.) with α=5%, power=90%, 5 |
|                                  | follow-up including baseline and |
|                                  | 10% dropout rate, the required   |
|                                  | sample size for this study was   |
|                                  | determined to be 80 (n = 40)     |
|                                  | using the G-Power software       |
|                                  | v3.1.9.4.                        |
|                                  |                                  |
|                                  | **Randomisation:** The data will |
|                                  | be randomized into two distinct  |
|                                  | groups utilizing a variable      |
|                                  | block size approach (with block  |
|                                  | sizes of 2, 4, 6, 8, 10, 12 and  |
|                                  | 14) generated through the        |
|                                  | statistical software Stata. This |
|                                  | randomization will ensure that   |
|                                  | the allocation ratio between the |
|                                  | two groups remains 1:1, thereby  |
|                                  | maintaining balance and          |
|                                  | comparability between the        |
|                                  | intervention and control groups  |
|                                  | throughout the trial.            |
|                                  |                                  |
|                                  | **Group 1: Full pulpotomy With   |
|                                  | occlusal reduction (test         |
|                                  | group)**                         |
|                                  |                                  |
|                                  | Selective grinding will be       |
|                                  | performed with Wheel diamond     |
|                                  | burs (MANI, Japan) under         |
|                                  | constant air-water coolant until |
|                                  | the teeth reach 0%               |
|                                  | post-intervention relative       |
|                                  | percentage of the occlusal force |
|                                  | as will be appreciated on the    |
|                                  | monitor screen with v10 of       |
|                                  | T-Scan running and will show a   |
|                                  | real-time decrease in relative   |
|                                  | percentage of occlusal force.    |
|                                  |                                  |
|                                  | **Group 2: Full pulpotomy        |
|                                  | Without Occlusal Reduction (     |
|                                  | control group)**                 |
|                                  |                                  |
|                                  | To simulate occlusal reduction,  |
|                                  | a high-speed handpiece under     |
|                                  | air-water coolant will be        |
|                                  | activated inside the patient's   |
|                                  | mouth without contacting the     |
|                                  | tooth surface. A post operative  |
|                                  | occlusal scan by T-Scan Novus    |
|                                  | will be done in the same manner  |
|                                  | as earlier to confirm no         |
|                                  | difference in the percentage of  |
|                                  | relative occlusal force.         |
|                                  |                                  |
|                                  | **Blinding:** The participants   |
|                                  | would be blinded (single blinded |
|                                  | study)                           |
|                                  |                                  |

|                                  | **6.5 Clinical procedure:**      |
|                                  |                                  |
|                                  | Patients will be requested to    |
|                                  | rinse the oral cavity with 10 ml |
|                                  | of 0.2% chlorhexidine            |
|                                  | digluconate (Aster-x, Sandika    |
|                                  | Pharmaceuticals Pvt. Ltd. New    |
|                                  | Delhi). Inferior alveolar nerve  |
|                                  | block (IANB) (Lox 2%, Neon Lab., |
|                                  | New Delhi) will be administered  |
|                                  | to anaesthetize the concerned    |
|                                  | tooth/teeth. After 15 minutes,   |
|                                  | the tooth will be subjected to   |
|                                  | EPT (Sybron Endo Vitality        |
|                                  | Scanner 2006, Sybron Endo). A    |
|                                  | negative response would ensure a |
|                                  | successful nerve block.          |
|                                  |                                  |
|                                  | Once anesthesia has been         |
|                                  | achieved, a pre-operative        |
|                                  | occlusal analysis will be taken  |
|                                  | with T-Scan NOVUS (T-Scan Novus, |
|                                  | Teckscan, Norwood,               |
|                                  | Massachusetts, U.S.A.) and       |
|                                  | pre-operative percentage of      |
|                                  | relative occlusal force between  |
|                                  | the tooth to be treated and its  |
|                                  | opposing tooth in centric        |
|                                  | occlusion and right and left     |
|                                  | lateral excursion will be noted. |
|                                  | The test will be repeated        |
|                                  | several times and an average     |
|                                  | score will be obtained. The      |
|                                  | tooth to be treated will then be |
|                                  | isolated with rubber dam. The    |
|                                  | carious lesion will be removed   |
|                                  | and any missing proximal wall    |
|                                  | will be restored with composite  |
|                                  | resin. Access to the pulp        |
|                                  | chamber will be gained using a   |
|                                  | round diamond bur (\# 1013,      |
|                                  | Microdont, Sao Paulo, Brazil)    |
|                                  | operated at high speed under     |
|                                  | air-water coolant. Visual        |
|                                  | inspection will be done to       |
|                                  | observe the presence of bleeding |
|                                  | pulp tissue to confirm pulp      |
|                                  | vitality. The inflamed coronal   |
|                                  | pulp tissue will be removed      |
|                                  | using a bur till the level of    |
|                                  | canal orifice. A small cotton    |
|                                  | pellet moistened with 2.5%       |
|                                  | sodium hypochlorite will be      |
|                                  | applied at the orifices for 2    |
|                                  | minutes and repeated up to 4     |
|                                  | times if required; the time to   |
|                                  | achieve haemostasis was          |
|                                  | recorded. If bleeding still      |
|                                  | continues pulpectomy will be     |
|                                  | initiated and the case will be   |
|                                  | excluded from the study. Once    |
|                                  | haemostasis will be achieved, a  |
|                                  | bioceramic endodontic material   |
|                                  | Biodentine (SEPTODONT 58, rue du |
|                                  | Pont de Créteil 94107            |
|                                  | Saint-Maur-des-Fossés Cedex      |

**[TITLE]{.underline}**

Effect of occlusal reduction on post operative pain and outcome of full
pulpotomy performed in permanent mature mandibular molar teeth with
symptomatic irreversible pulpitis and sensitivity to percussion: A
Randomized Controlled Trial

**[INTRODUCTION]{.underline}**

Pulpitis is a sequelae to an insult by microbial, chemical, or physical
irritants (mechanical and thermal).^1^ According to the American
Association of Endodontics (AAE) consensus on diagnostic terminology,
pulpitis can be either reversible or irreversible.^2^ Pulpitis is deemed
as reversible when the pulp can predictably return to normal conditions
after the removal of the irritant stimulus.^3^

Teeth diagnosed with irreversible pulpitis are characterized by having
spontaneous, intense and lingering pain (often lasting 30 seconds or
more after stimulus removal) that is often triggered by thermal
stimuli.^2^ One study found that more than 50% of patients diagnosed
with symptomatic irreversible pulpitis (SIP) presented with mechanical
allodynia, indicating a significant incidence of percussion sensitivity
in this condition.^37^ Reportedly, pain due to irreversible pulpitis is
the etiological factor for more than 45% of emergency dental visits.^1^
However, as dental caries progresses, it destroys dentin and approaches
the pulp with the inflammatory response becoming more intense increased
in magnitude as the diseased state of the pulp progresses. The
inflammatory condition of the pulp at this stage is changed to
irreversible pulpitis*.*^1,4^ In irreversible pulpitis, the ability of
pulp to return to its normal architecture becomes minimal even after
removal of the irritant and hence requires partial or total excision of
the affected pulp tissue.^4^ This condition can be subdivided into
symptomatic and asymptomatic irreversible pulpitis^2^.

According to guidelines given by AAE in
2013,[^1^](https://www.zotero.org/google-docs/?broken=5m62FZ) the teeth
with symptomatic irreversible pulpitis are characterized by sharp pain
upon thermal stimulus which is lingering (often 30 seconds or longer
after stimulus removal), spontaneous (unprovoked pain) and may refer to
surrounding anatomical structures. A clinical diagnosis is based on
subjective and objective findings indicating that the vital inflamed
pulp is incapable of
healing[^1^](https://www.zotero.org/google-docs/?broken=4pKMue).
Mechanical allodynia in irreversible pulpitis may be attributed to
various factors, including activation of pulpal mechanoreceptive
nociceptive neurons, diffusion of inflammatory mediators or bacterial
byproducts into the periradicular space, and central sensitization
resulting from the activation of pulpal nociceptors.^37^ This
incapability of healing of pulp in symptomatic irreversible pulpitis is
based on the strangulation theory which hypothesized that due to
inflammation there is an increase in pulpal pressure in the
low-compliant pulp from normal to higher magnitude.^4,5^ Theoretically,
the tissue pressure may soon reach a magnitude that results in
compression of the blood vessels which ultimately leads to pulp
degeneration.^1,3^ The preferred treatment of choice in such a scenario
will be conventional non-surgical endodontic treatment (NSET) which has
a success rate of 95% with an excellent prognosis.^6^

The purpose of NSET is to completely remove the infected or inflamed
pulp tissue, shape the canal space, and establish a bacteria-tight seal
to promote healing and retain natural tooth function.^3^ The success
rate of NSET depends on factors like proper diagnosis after correlation
of clinical and radiographic features, extent of carious lesion,
disinfection protocols, instrumentation, filling procedures, and
post-treatment care.^7^ Research indicates success rates of NSET to vary
between 86 - 97%.^6--8^ Criteria for a successful outcome are determined
by the elimination of pain, presence of a bacteria-tight seal of the
canal space, retention of the tooth, and preservation of natural tooth
function.^3,7^ However, a small proportion of patients may still
experience post-operative pain following root canal procedure,
prevalence of which ranges from 3% - 58% ^8,10^. An endodontically
treated tooth with foreign root canal filling materials is biologically
inferior to the original dental pulp because root canal filling
materials lack biological immune defence mechanism and sensory nerve
innervation. One of the many reasons resulting in post operative pain
following NSET is due to persistent sensitivity to percussion following
NSET, which is not addressed by the treatment. Additionally, the
survival rate of endodontically treated teeth has been reported to be
lower than that of vital teeth.^10^ Multiple factors which can be
attributed towards the same include persistence of bacteria, inadequate
filling of the canal, and iatrogenic procedural errors.^8^

Occlusal reduction is a technique that has shown promising result for
managing postoperative pain by addressing occlusal discrepancies and
mechanical allodynia.^9^ Occlusal reduction involves the intentional
reduction of the occlusal surface of the tooth to achieve evenly
balanced and distributed occlusal forces across the dental arch.^9,11^
Reducing occlusal contacts may lower the mechanical stimulation of
peripheral nociceptor terminals which are believed to decrease pain
levels and the effects of mechanical allodynia.^9,12,37^ By adjusting
occlusal contacts, the goal is to create a more stable and balanced
occlusion that promotes healing and reduces the likelihood of pain or
sensitivity after dental procedures.^13^ It is important to note that
the effectiveness of occlusal reduction in reducing post-operative pain
may vary depending on individual patient factors, the specific diagnosis
of the tooth being treated, pre-operative pain score, and periapical
status of the tooth.^14^ Study by Ahmed et.al.,(2020) showed that
occlusal reduction was associated with significantly less pain intensity
at 12h and 24h post-instrumentation. Additionally, the study found a
decrease in postoperative analgesic intake in the occlusal reduction
group, highlighting the potential benefits of this intervention in
managing post-treatment pain. Systematic reviews mentioned potential
benefit of occlusal reduction while mentioning the need for further
high-quality clinical trials to better understand its role.^9,11,12^

However nowadays, an alternate definitive treatment that has been
considered in teeth diagnosed with symptomatic irreversible pulpitis is
pulpotomy.^3^ Based upon clinical and radiographic evaluation, two types
of pulpotomy can be performed in teeth with SIP: Full and Partial
pulotomy .^15^ Full pulpotomy refers to complete removal of the coronal
pulp and application of a biomaterial directly onto the pulp tissue at
the level of the root canal orifice(s), prior to placement of a
permanent restoration.^15^ In cases of pulpotomy, where the coronal pulp
is removed to treat irreversible pulpitis, the formation of tertiary
dentin is observed at the site of the pulp exposure.^16^ Histologically,
this tertiary dentin appears as a reparative dentin bridge that
gradually forms over time, contributing to the sealing of the pulp
chamber with calcium silicate bio-material and protecting the remaining
vital pulp tissue.^15,16^ Additionally, histological analysis of teeth
post-pulpotomy often reveals a reduction in inflammation within the pulp
tissue as the reparative process progresses. The decrease in
inflammation is indicative of the pulp\'s healing response to the
treatment intervention, with the formation of tertiary dentin playing a
key role in this regenerative process.^4,16^

The success rate of full pulpotomy using Biodentine in young permanent
teeth with carious exposure was reported to be 95% at 1-year
follow-up.^17^ The study demonstrated high clinical and radiographic
success rates, with most cases showing total pain relief with dentin
bridge formation and healing of periapical rarefaction.^17^ Asgary S et
al (2010)^18^ in their study compared postoperative pain relief after
single visit NSET and pulpotomy and concluded that the mean pain
intensity and duration were significantly lower in the full pulpotomy
group.^18^ All patients in the pulpotomy group reported complete relief
of pain at 18 hour post-operatively compared to 36 hour in NSET group,
indicating that the patients experienced significant pain relief shortly
after the treatment.^18^ In another study by Taha and Al-khatib^19^
(2022), full pulpotomy was performed in symptomatic permanent mature
teeth with carious pulp exposure and the authors reported a high success
rate over a 4-year follow-up period. The overall mean survival time of
pulpotomy was 3.89 years, with cumulative survival rates of 98%, 97.4%,
93%, and 83.8% at 6 months and 1, 2, and 4 years, respectively.^19^ In
another similar study where cases of irreversible pulpitis having
moderate to severe levels of preoperative pain were treated with
pulpotomy and NSET, the mean pain score after full pulpotomy was
significantly lower than the mean pain score after NSET on day 1
post-operatively. At subsequent follow-up intervals of day 2, 3, and 5,
the pain levels were still lower with no statistically significant
difference. The full pulpotomy group had a significantly lower
percentage of patients taking analgesics after treatment than the NSET
group.^20^ The literature thus indicates lower levels of post operative
pain after pulpotomy was performed in teeth diagnosed with SIP. However,
a study by Shallal-Ayzin et al., (2021) highlights a high success rate
of patients undergoing full pulpotomy but varying levels of
postoperative pain, with approximately one-third of patients reporting
some degree of pain.^21^ Galani et.al. (2017)^35^ noted that 70% of
patient following full pulpotomy had slight to moderate pain on 1st day
and then from following day onwards reported no to very slight pain till
fifth day after treatment. In another similar study result showed that
patients experienced mild to moderate pain in the immediate
postoperative period, which typically resolved within a week.^21^
Notably, the study found that continued pain at the 3-month evaluation
point was significantly associated with an unfavourable outcome of VPT,
emphasizing the importance of monitoring postoperative pain as a
predictor of treatment success.^20,21^

Our hypothesis is mechanical allodynia is one of the reasons for the
occurrence of post operative pain in teeth with SIP and sensitivity to
percussion treated with full pulpotomy, and by occlusal reduction the
incidence of post operative pain may be minimized by relieving the tooth
from mechanical allodynia. Until now, no study in the literature has
evaluated the effect of occlusal reduction on post operative pain
following full pulpotomy performed in permanent mature mandibular molar
teeth with symptomatic irreversible pulpitis and sensitivity to
percussion. Therefore, the current study aims to evaluate the effect of
occlusal reduction on post operative pain and outcome of full pulpotomy
performed in permanent mature mandibular molar teeth with symptomatic
irreversible pulpitis and sensitivity to percussion**[.]{.underline}**

This Randomized Controlled Trial (RCT) titled \"Effect of Occlusal
Reduction on Postoperative Pain and Outcome of Full Pulpotomy Performed
in Permanent Mature Mandibular Molar Teeth with Symptomatic Irreversible
Pulpitis and Sensitivity to Percussion\" was conducted in adherence to
the Consolidated Standards of Reporting Trials (CONSORT) guidelines.

**1. Effects of occlusal reduction on post-operative pain following
NSET.**

**Jostes JL, Holland GR.** ^22^ in 1984 published one of the earliest
research papers on the effect of occlusal reduction. In the study of 58
patients divided into two groups, there was no significant difference in
total amount, maximum intensity or duration between the OR group and
non-OR group. However, it was noted that patients who were not tender to
the initial bite test tended to be more comfortable when the occlusion
was left intact. Conversely, patients uncomfortable with the initial
bite test experienced lower discomfort levels when the occlusion was
relieved.

**Creech JL 3rd, Walton RE, Kaltenbach R**. ^23^ in 1984 published a
randomized controlled trial in which 49 patients receiving endodontic
treatment were randomly assigned to either an occlusal relief group or a
mock-occlusal relief group. The occlusal relief group had their teeth
reduced out of occlusion, while the mock-occlusal relief group had
minimal tooth structure removed from a nonfunctional cusp. Patients were
followed up for 48 hours and the results indicated that spontaneous pain
levels and pain from occlusal pressure were not significantly different
between the two groups, but the levels of spontaneous pain were
significantly related to pre-operative pain, irrespective of the
intervention group.

**Rosenberg PA et.al** ^14^ (1998) published a randomized controlled
trial with 117 patients divided into three groups viz. total occlusal
reduction, stimulated reduction and control (no reduction) and followed
up for 48 hours post-instrumentation. Results emphasize the importance
of considering these preoperative conditions such as preoperative pain,
pulp vitality, percussion sensitivity, and absence of periradicular
radiolucency when determining which patients are most likely to benefit
from occlusal reduction. The presence of any one or more of these
conditions indicates a potential benefit of occlusal reduction to reduce
post-instrumentation pain.

**Parirokh M et.al.** ^24^ in 2013 published an article aimed to
investigate the effect of occlusal reduction on postoperative pain in
patients with irreversible pulpitis and mild tenderness to percussion
undergoing root canal treatment. \`OR group had all occlusal contacts on
the functional and non-functional cusps as well as on the marginal
ridges reduced by 1 mm by using a diamond bur. The study also evaluated
and compared post-operative analgesic intake and their effect on a scale
that has a range of 0 to 2 (where 0: None or mild pain that does not
require analgesic medication 1: Moderate pain that was fairly well
controlled with analgesic medication and did not interfere with sleep or
daily activities 2: Unbearable pain that was not controlled with
analgesic medication and interfered with daily activities), Ibuprofen
600mg was prescribed every 6 hour if they felt pain. Patients were
instructed to self-evaluate themselves for 6 days through printed form.
The study found no significant difference in postoperative pain and
analgesic intake between the OR group and the NOR group and therefore
concluded that occlusal reduction may not be necessary in such cases to
alleviate postoperative pain.

In the literature, the majority of the research done on occlusal
reduction used articulating paper to determine the presence or absence
of occlusal contacts but the use of articulating paper for occlusal
analysis presents several disadvantages. Firstly, the interpretation of
the marks left by the paper is highly subjective and can vary between
individuals, leading to inconsistent assessments. Additionally,
articulating the paper may not provide a comprehensive evaluation of
occlusal contact simultaneity, potentially overlooking critical aspects
of the occlusal relationship. The reproducibility of results obtained
with articulating paper is also a concern, as they may not be easily
replicated. Moreover, the paper lacks the sensitivity needed to detect
subtle differences in occlusal contacts, which can be crucial for
accurate analysis. The pressure applied during the biting process can
further influence the results, introducing a degree of inaccuracy.
Lastly, while the articulating paper offers qualitative information, it
does not provide precise quantitative data on occlusal forces, limiting
its utility in detailed occlusal analysis ^13,25^.

The use of T-Scan for occlusal analysis offers several significant
advantages over articulating paper. Firstly, T-Scan provides objective
and quantitative data on occlusal contacts and forces, offering a more
precise assessment compared to the qualitative information obtained from
the articulating paper. It allows for real-time evaluation of occlusal
contacts during mandibular movements, providing immediate feedback on
occlusal dynamics. Additionally, T-Scan offers good reproducibility of
surface measurements and the registration of relative forces, enhancing
the reliability of the data obtained. Its high sensitivity enables the
detection of primary contacts and excessive occlusal forces, allowing
for the identification of subtle occlusal discrepancies. Unlike
articulating paper, T-Scan is not affected by saliva, ensuring
consistent and accurate results even in the presence of moisture.
Furthermore, T-Scan provides a comprehensive evaluation of occlusal
contact distribution, offering detailed insights into occlusal dynamics
and potential areas of concern^13,25^.

**Arslan H et.al.** ^13^ in 2017 published a study that investigated the
influence of occlusal reduction on postoperative pain in teeth with
symptomatic apical periodontitis using a computerized occlusal analysis
system -- T-Scan III for Windows. 39 subjects with severe pre-operative
pain (VAS \>80mm) were divided into three equal groups: control group
(no reduction), semi-reduction group (partial reduction), and
full-reduction group (complete reduction). Instead of occlusal contact,
pre- and post-operative relative percentage of occlusal force was taken
into account for OR. No significant differences were found in
postoperative pain levels and analgesic intake among the three groups at
1, 3, 5, and 7 days after treatment. The study concluded the occlusal
reduction did not impact postoperative pain in teeth with symptomatic
apical periodontitis.

**Emara R.S. et.al**., ^26^ in 2019 published a randomized clinical
trial that investigated the effect of occlusal reduction on
postoperative pain in mandibular posterior teeth with symptomatic
irreversible pulpitis and apical periodontitis. The study included 44
patients with moderate to severe preoperative pain, divided into
intervention and control groups. Postoperative pain levels decreased
significantly over time in both groups, with lower pain scores in the OR
group at various follow-up periods. The difference was significant at 12
hours post-treatment. There was no significant difference in
postoperative analgesic intake between the groups. The study concluded
that occlusal reduction may contribute to reducing postoperative pain in
teeth with symptomatic irreversible pulpitis and symptomatic apical
periodontitis.

**Ahmed et al.** ^27^ in 2020 published a randomized controlled trial
that aimed to evaluate the impact of occlusal reduction on
post-treatment endodontic pain in mandibular posterior teeth with
symptomatic irreversible pulpitis. 308 patients were divided equally
into two groups (OR and non-OR) and at the end of the appointment were
dismissed with sham analgesic containing powdered milk to be taken in
case of pain. If pain persisted, the patient was instructed to contact
the operator who would then prescribe an analgesic Ibuprofen 400 mg.
Results showed that occlusal reduction was associated with significantly
less pain intensity at 12h and 24h post-instrumentation. Additionally,
the study found a decrease in postoperative analgesic intake in the
occlusal reduction group, highlighting the potential benefits of this
intervention in managing post-treatment pain.

**Nguyen‐Nhon et.al**., ^11^ in 2019 published a systematic review and
meta-analysis in which seven studies were analysed, with three included
in the meta-analysis for post-operative pain assessment at 6 days, while
the remaining studies underwent qualitative synthesis. The findings
indicated that occlusal reduction potentially diminishes post-operative
pain, particularly for teeth diagnosed with irreversible pulpitis, with
an overall reduction in pain for patients presenting with irreversible
pulpitis and/or symptomatic apical periodontitis. The review highlighted
the need for future high-quality clinical trials to further elucidate
the role of occlusal reduction in enhancing patient outcome following
endodontic procedures.

**Shamszadeh et al**. ^9^ in 2020 systematic review and meta-analysis
aimed to evaluate the efficacy of occlusal reduction in controlling
post-operative endodontic pain in adults undergoing root canal therapy.
The study included six randomized controlled trials with a total of 344
participants and found that occlusal reduction did not significantly
reduce pain intensity scores at 12-, 24- and 48-hours post-treatment
compared to placebo. However, at the 72-hour mark, patients who received
occlusal reduction showed a significant reduction in pain compared to
the placebo group. The authors concluded that while occlusal reduction
may not have a significant impact on pain control up to 2 days
post-treatment, it could be beneficial in managing post-endodontic pain
on the third day. Further research with larger sample sizes and
standardized methodologies is recommended to provide more conclusive
evidence on the effectiveness of occlusal reduction in post-endodontic
pain management

**2. Comparison of post-operative pain and success rate in teeth
diagnosed with SIP treated with Full pulpotomy and NSET.**

**Taha and Abdulkhader** ^17^ in 2018 published a study involving 20
young permanent teeth with carious exposure and symptoms of irreversible
pulpitis, full pulpotomy using Biodentine demonstrated a high success
rate of 95% at the 1-year follow-up. Two days postoperatively, all
patients reported complete relief of pain, indicating effective pain
management. Clinical evaluations at 6 months and 1 year showed no
spontaneous pain or discomfort in any of the cases, with continued root
development and dentin bridge formation observed in some teeth. The
study concluded that young permanent teeth with carious exposure can be
successfully treated with full pulpotomy using Biodentine, even in cases
with clinical signs and symptoms of irreversible pulpitis.

**Taha and Abdelkhader** ^28^ included 64 permanent molar teeth with
symptoms indicative of irreversible pulpitis. Preoperative diagnoses
confirmed symptomatic vital pulps and periapical rarefaction in some
cases. After pulpotomy using Biodentine canal orifices were sealed, and
teeth were restored with resin composite or amalgam. Clinical and
radiographic evaluations at 6 months and 1 year postoperatively showed a
high success rate, with 98.4% and 100% clinical success, respectively.
Radiographic success was 98.4% at 6 months and 100% at 1 year.
Postoperative pain relief was significant, with 93.8% reporting complete
pain relief after 2 days. The study concluded that full pulpotomy using
Biodentine in adult patients with carious exposures and symptoms of
irreversible pulpitis resulted in high success rates and significant
pain relief, supporting the rationale for this treatment approach in
such cases.

**Taha and Al-Khatib** ^19^ in 2022 published a study involving 100
symptomatic mature permanent teeth with carious pulp exposure who
underwent full pulpotomy, the procedure demonstrated a high success rate
over a 4-year follow-up period. The cumulative survival rates were 98%,
97.4%, 93%, and 83.8% at 6 months and 1, 2, and 4 years, respectively.
Postoperatively, there was a significant improvement in pain severity,
with 97% of patients reporting complete relief or mild pain within the
first week after treatment. The study concluded that full pulpotomy in
cariously exposed pulp of mature permanent teeth sustained a high
success rate over 4 years, emphasising the importance of a good coronal
seal for long-term survival.

**Eghbal et.al**., ^20^ in 2020 published a study that included 550
participants with mature teeth and carious pulp exposure randomized into
three groups: pulpotomy with mineral trioxide aggregate (PMTA),
pulpotomy with calcium-enriched mixture (PCEM), and root canal treatment
(NSET). The baseline characteristics and preoperative conditions were
similar across the groups. Postoperative pain intensity was
significantly reduced within 1 day after treatment and remained minimal
over 7 days. The study concluded that pulpotomy with MTA or CEM and NSET
provided comparable and effective postoperative pain relief in mature
teeth with carious pulp exposure. Despite limitations such as the
open-label design and lack of socioeconomic status assessment the large
sample size and rigorous randomisation process enhanced the validity of
the results.

 

**McHugh et.al**., ^29^ 2023 systemic review on pulpotomy in permanent
mature posterior teeth with moderate to severe pulpitis examined various
diagnostic and prognostic factors influencing treatment outcome. Success
rates of pulpotomy procedures varied among studies, with some reporting
high success rates comparable to root canal treatment. Additionally,
post-operative pain outcome were a significant focus, with evidence
suggesting that pulpotomy resulted in lower postoperative pain in the
short term compared to other treatments. These findings highlight the
potential of pulpotomy as an effective and less painful alternative for
managing moderate to severe pulpitis in adult teeth, emphasizing the
importance of further research to optimize treatment protocols and
enhance patient outcome.

**Shallal-Ayzin et.al.,** ^21^ 2021 article presents a prospective
analysis on the correlation between postoperative pain and vital pulp
therapy (VPT). The study highlights a high success rate of VPT in
maintaining pulp vitality, particularly in asymptomatic teeth with
cariously exposed pulps. Patients undergoing VPT experienced varying
levels of postoperative pain, with approximately one-third reporting
some degree of pain. Most patients experienced mild to moderate pain in
the immediate postoperative period, which typically resolved within a
week. Notably, the study found that continued pain at the 3-month
evaluation point was significantly associated with an unfavourable
outcome of VPT, emphasizing the importance of monitoring postoperative
pain as a predictor of treatment success

**Alhilou et.al.,**^30^ 2023 published a systematic review on
postoperative pain after emergency treatments for symptomatic
irreversible pulpitis and symptomatic apical periodontitis in permanent
dentition revealing that both pulpotomy and pulpectomy are effective
options for alleviating endodontic pain. The 5 included studies
indicated that pulpotomy and pulpectomy provide sufficient pain relief,
with varying results on which treatment is more effective in reducing
pain. The success rates of the treatments were relatively high, with
pulpotomy showing success rates of 85% and pulpectomy 87%. Postoperative
pain assessment using numeric rating scales and visual analogue scales
showed inconsistent findings among the studies

**Taha et.al.,** ^31^ in 2023 published a study that included 52 teeth
divided equally between pulpotomy and NSET groups to compare their
effectiveness in treating mature teeth with irreversible pulpitis. The
success rates of both treatments were high, with 27 out of 29 teeth in
each group showing success at the 1-year follow-up. Pulpotomy provided
quicker pain relief post-operatively, with significantly lower mean pain
scores compared to root canal therapy on day 1. Additionally, fewer
patients in the pulpotomy group required analgesics after treatment.
Overall, patients reported high satisfaction with both treatments, with
pulpotomy scoring significantly higher in terms of time involved,
intraoperative pain, pleasantness, and cost. The study concluded that
pulpotomy can be a viable alternative to root canal therapy in certain
cases of irreversible pulpitis, offering comparable success rates and
improved post-operative pain outcome.

[**Sample size calculation**:]{.underline}

Sample size is calculated based study done by Taha et al (2023),
considering the average pain score following pulpotomy to be 2.19 ± 3.25
during seven days and on assuming a small effective size of 0.15
(0.5/3.25) between Occlusal reduction and Non-occlusal reduction groups
(i.e, 0.15 less in O.R.) with α=5%, power=90%, 5 follow-up including
baseline and 10% dropout rate, the required sample size for this study
was determined to be 80 (n = 40) using the G-Power software v3.1.9.4.

**[Randomisation]{.underline}**

The data will be randomized into two distinct groups utilizing a
variable block size approach (with block sizes of 2, 4, 6, 8, 10, 12 and
14) generated through the statistical software Stata. This randomization
will ensure that the allocation ratio between the two groups remains
1:1, thereby maintaining balance and comparability between the
intervention and control groups throughout the trial.

**[PRE-OPERATIVE CLINICAL ASSESSMENT:]{.underline}**

**[Extra-oral examination:]{.underline}**

Extra-oral examination will be done to rule out any facial swelling,
extra-oral sinus, palpable lymph nodes and facial asymmetry.

**[Intra-oral examination:]{.underline}**

**Palpation:** Index finger will be used to palpate mucosa covering the

**[Pulp Sensibility Testing:]{.underline}**

**Thermal test:**

Teeth will be isolated with cotton rolls and cold test will be performed
by placing a small cotton pellet sprayed with endo-frost over the buccal
cusp tip of the contralateral control tooth followed by the test tooth
to evaluate pulp vitality. The result will be recorded as a positive or
negative response.

**Electric pulp test:**

The teeth will be isolated with cotton rolls. The lip clip will be
attached on the corner of the mouth and the tip of the testing probe
coated with electrolyte gel will be placed in contact with the
mesiobuccal cusp tip, cervical and lingual aspect of the tooth. The
control tooth will be tested first in order to establish a baseline
response and to inform the patient as to what a "normal" sensation is.
The suspected tooth will be tested at least twice to confirm the
preliminary result. The result will be recorded as a positive or
negative response and EPT readings for positive response will also be
noted.

**[CLINICAL PROCEDURE:]{.underline}**

Patients will be requested to rinse the oral cavity with 10 ml of 0.2%
chlorhexidine digluconate **(Aster-x, Sandika Pharmaceuticals Pvt. Ltd.
New Delhi)**. Inferior alveolar nerve block (IANB) **(Lox 2%, Neon Lab.,
New Delhi)** will be administered to anaesthetize the concerned tooth.
After 15 minutes, the tooth will be subjected to EPT (**Sybron Endo
Vitality Scanner 2006, Sybron Endo)**. A negative response would ensure
a successful nerve block.

Once anaesthesia has been achieved, a pre-operative occlusal analysis
will be taken with **T-Scan NOVUS (T-Scan Novus, Teckscan, Norwood,
Massachusetts, U.S.A.)** and pre-operative percentage of relative
occlusal force between the tooth to be treated and its opposing tooth in
centric occlusion and right and left lateral excursion will be noted.
The test will be repeated several times and an average score will be
obtained. The tooth to be treated will then be isolated with rubber dam.
The carious lesion will be removed and any missing proximal wall will be
restored with composite resin restorative material. Access to the pulp
chamber will be gained using a round diamond bur (\# 1013, Microdont,
Sao Paulo, Brazil) operated at high speed under air-water coolant.
Visual inspection will be done to observe the presence of bleeding pulp
tissue to confirm pulp vitality. The inflamed coronal pulp tissue will
be removed using a bur till the level of canal orifice. A small cotton
pellet moistened with 2.5% sodium hypochlorite will be applied at the
orifices for 2 minutes and repeated up to 4 times if required; the time
to achieve haemostasis was recorded.^36^ If bleeding dosen't stop in 8
mins, pulpectomy will be initiated and the case will be excluded from
the study. Once haemostasis will be achieved, a bio-ceramic endodontic
material Biodentine **(SEPTODONT 58, rue du Pont de Créteil 94107
Saint-Maur-des-Fossés Cedex France)** will be mixed according to the
manufacturer's instructions and placed in a 2-3 mm layer above the pulp
tissue using MAP system and gently packed using a condenser. A layer of
RMGIC **(Vitrebond, 3M ESPE, St. Paul, MN, USA)** will be placed and
light-cured for 20 seconds. The tooth will finally be restored with
resin composite **(Tetric N-Ceram Bulk fill)** following standard
protocol and manufacturer instructions. Rubber dam will be removed after
this step. The teeth will be randomly divided into two groups as:

**Group 1: Full pulpotomy With occlusal reduction (test group)**

Selective grinding will be performed with Wheel diamond burs **(MANI,
Japan)** under constant air-water coolant until the teeth reach 0%
post-intervention relative percentage of the occlusal force as will be
appreciated on the monitor screen with v10 of T-Scan running and will
show a real-time decrease in relative percentage of occlusal force. All
the patients of group 1 will be recalled at 6-month interval for the
definitive prosthetic rehabilitation.

**Group 2: Full pulpotomy Without Occlusal Reduction (control group)**

To simulate occlusal reduction, a high-speed handpiece under air-water
coolant will be activated inside the patient's mouth without contacting
the tooth surface. A post operative occlusal scan by T-Scan Novus will
be done in the same manner as earlier to confirm no difference in the
percentage of relative occlusal force.

This will be followed by finishing and polishing that will be done with
appropriate polishing cups and points **(Shofu Dental Corporation, San
Marcos CA, U.S.A)** for both group 1 and group 2. After completing the
procedure, an intraoral periapical radiograph will be taken as a record.

**Patients in both the groups will be prescribed 10 tablets of Ibuprofen
600mg and advised to take it when experiencing moderate-severe
post-operative pain after consulting the doctor.**

**[POST OPERATIVE EVALUATION:]{.underline}**

All the patient at the end of the appointment will be dismissed with 10
tablets of Ibuprofen 600mg and will be instructed to take them 8 hourly
in case of moderate - severe pain (NRS \>6). The patient will be
informed about the regular telephonic consult which will be done by the
operator at 6 hours, 12 hours, 24 hours then daily till the 7^th^ day at
same time. The purpose of these consultations is to document the
patient\'s pain severity and analgesic intake. If the patient
experiences intense or excruciating pain, they will be asked to contact
the doctor through a telephonic consultation to describe the severity of
the pain. They will also be advised to take an additional tablet and
visit the doctor. If the patient\'s discomfort is not alleviated, they
will be classified as a failed case and will undergo pulpectomy
treatment.

All patients will be followed through telephonic consult
post-operatively will be evaluated for:

1.  **Occurrence and intensity of postoperative pain**.

> Post-operative pain will be recorded on an 11-point NRS as done
> pre-operatively.

2.  **Consumption and effect of analgesic for relieving postoperative
    pain if any**.

> To Analgesic consumption will be recorded for assessing the necessity,
> dosage (i.e., no. of tablets) and efficacy of analgesics using a
> 3-point scale based on Parirokh et al. ^24^

**Method of study:**

You have a decayed tooth that is the cause for your pain. An x-ray will
